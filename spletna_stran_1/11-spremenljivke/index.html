Definicija

Spremenljivka je imenovan prostor v računalniškem pomnilniku (RAM), v katerega program začasno shranjuje podatke (npr. števila, besede, rezultate izračunov). Vrednost spremenljivke se lahko med izvajanjem programa spreminja, zato ji pravimo spremenljivka. Spremenljivke uporabimo za hranjenje vrednosti, ki jih bomo kasneje v programu še potrebovali.

Lastnosti spremenljivke

  • ima ime (npr. starost, ime, vsota)

  • ima vrednost (npr. 15, "Ana")

  • ima tip podatka (npr. število, znak, besedilo …)

  • vrednost se lahko spremeni

  • ko se vrednost spremeni, nova vrednost nadomesti staro (stara več ni dostopna)

Zakaj uporabljamo spremenljivke?

  • da shranjujemo podatke med izvajanjem programa za kasnejšo uporabo

  • da lahko računamo, preverjamo pogoje, prikazujemo rezultate

  • da lahko program dela z različnimi podatki (vnos uporabnika, števila, besedila)

Preprosta razlaga

Predstavljaj si spremenljivko kot škatlo z nalepko:

  • nalepka = ime spremenljivke

  • kar je v škatli = trenutna vrednost

  • lahko zamenjaš vsebino, ime pa ostane isto

Deklaracija

Deklaracija spremenljivke je napoved, da bomo spremenljivko uporabljali. Spremenljivke ne moremo uporabljati, če je prej ne deklariramo. Spremenljivko z istim imenom lahko deklariramo samo enkrat.

podatkovni_tip ime_spremenljivke;

primer:

int x;
String y;

byte z;

char znak1, znak2;

Naloga:

Ustvari spremenljivko za hranjenje spola (m ali ž). Spremenljivko poimenuj spol. V spremenljivko shrani vrednost m. Izpiši vrednost spremenljivke v tej obliki (spol=m). Enako naredi za ime razreda (3.ag) in starost (18).

Podatkovni tip

Podatkovni tip v javi določa:

  • vrsto podatka (npr. celo število, realno število, znak, besedilo ali logično vrednost), ki ga lahko shranjuje spremenljivka

  • koliko pomnilnika (velikost) bo zasedel v primarnem pomnilniku (RAM) (npr. 1B, 2B, 4B ali 8B, pri čemer je 1B = 8 bitov)

  • kakšne operacije lahko izvajamo nad podatki in kaj te operacije pomenijo

Ker je java strogo tipiziran jezik (tudi »type safety« ali »strictly typed« ), moramo ob deklaraciji vedno navesti tip spremenljivke (npr. byte, int, char, long, float, double, boolean). Pri nekaterih drugi programskih jezikih, to ni potrebno (PHP, python, ...)

Podatkovni tip določa tudi, kakšne operacije lahko izvajamo nad podatki.

Primeri:

Dve celi števili: 1 + 1 = 2 (+ seštevanje)

Niz in celo število: "1" + 1 = 11 (+ dodajanje, združevanje, concatenation)

Dve celi števili: 1/2 = 0 (/ celoštevilsko deljenje)

Realno število in celo število: 1.0/2 = 0.5 (/ realno številsko deljenje)

Prav tako opisuje način fizičnega shranjevanja podatkov v pomnilniku, kar omogoča optimizirano porabo pomnilnika ter učinkovito delovanje programa.

Zakaj so podatkovni tipi pomembni?

  • java preveri pravilnost programiranja že ob prevajanju

  • program je bolj varen, hitrejši in pregleden

  • varuje pred napakami, kot je seštevanje besedil (napaka)

Skupine podatkovnih tipov

Podatkovne tipe v Javi lahko razdelimo v dve glavni skupini, ki se razlikujeta po načinu shranjevanja, delovanju in uporabi:

  • primitivni (primitive data type)

  • referenčni (reference or non-primitive data tpye)

Primitivni podatkovni tipi

To so osnovni, vnaprej določeni tipi, ki jih pozna java.

Lastnosti:

  • imena se začnejo z malo črko (int, char, ...)

  • shranjujejo enostavne vrednosti

  • velikost v pomnilniku je fiksna

  • ne vsebujejo metod

  • vrednosti se shranjujejo direktno v pomnilnik (ne kot objekti)

  • so hitrejši

Referenčni (objektni) podatkovni tip

So vsi tipi, ki niso primitivni, in predstavljajo objekte oziroma strukture podatkov.

Lastnosti:

  • začnejo se z veliko črko (npr.: String, Scanner, Random, ...)

  • ne shranjujejo same vrednosti, ampak referenco (naslov) v pomnilniku

  • vsebujejo metode in dodatne funkcionalnosti

  • velikost v pomnilniku ni fiksna

  • so počasnejši, a zmogljivejši

Tip Primer
String niz znakov
ArrayList seznam
Scanner branje iz konzole
uporabniški razredi npr. Student, Avto

Objekt ustvarimo malo drugače kot primitivno spremenljivko. Izjema je String! Prepoznamo ga po besedici new.

Primer:

Scanner scn = new Scanner(System.in);

Random rnd = new Random();

String stavek = "To je stavek!"; // IZJEMA!!!

Inicializacija spremenljivke. Spremenljivki določimo (prvo - začetno) vrednost.

x = 7;

y = "Marko";

z = 9;

float f = 1.5f;

V enem stavku, lahko deklariramo in/ali inicializiramo več spremenljivk naenkrat. Ločimo jih z vejico.

int x = 5, y, z = 50;

Pravila poimenovanje spremenljivk:

  • Imena lahko vsebujejo: črke, številke, podčrtaj, dolar.

  • Ime se mora začeti s črko ali podčrtajem ali dolarjem.

  • Ime ne sem vsebovati presledka.

  • Imena so »case sensitive«. Stevilo, stevilo, STEVILO so različne spremenljivke.

  • Ime ne sme biti rezervirana beseda (int, byte, for, while, if, …).

  • Imena spremenljivk morajo biti unikatna. Dve spremenljivki ne smeta imeti istega imena.

Primeri pravilnega poimenovanja:

  • Person

  • AccountDetails

  • _$Order (though $ as a starting character is not recommended)

  • Customer_123

Primeri NE-pravilnega poimenovanja:

  • 1Person (zečne se s števko)

  • class (rezervirana beseda java)

  • Customer-Info (vsebuje pomišljaj)

Uporabimo stil »camelCase«:

  • firstName

  • totalPrice

  • studentAge

Izogibamo se okrajšavam ali nerazumljivim imenom, da je koda bolj berljiva in vzdrževana.

Konstantna spremenljivka

Konstantna spremenljivka je primitivna spremenljivka, katere vrednost programer ali uporabnik ne more spremeniti, ko je enkrat določena.

final int PI = 3.14;

PI = 5; // ne gre – konstante spremenljivke ne moremo spreminjati, ko enkrat ime vrednost,

Imena konstantnih spremenljivk navadno pišemo s samimi velikimi črkami.

Literali

Literali v javi so neposredno zapisane vrednosti v programu. To so stalne, fiksne vrednosti, ki jih zapišemo kar v kodo, brez izračuna ali spremenljivk.

Primeri literalov:

  • številski: 10, 3.14, -5, 7.2f

  • logični: true, false

  • znakovni: 'A', '\n'

  • nizovni: "Pozdrav"

  • posebni: null

Doseg spremenljivke (scope)

Doseg spremenljivke (tudi veljavnost ali ang. scope) pomeni, v katerem delu programa je spremenljivka dosegljiva (vidna) in jo lahko uporabljamo.

Spremenljivka je dosegljiva samo v območju, kjer jo deklariramo. Območje ali programski blok (ang. block of code) je območje med zavitimi oklepaji { }.

Blok kode lahko stoji samostojno ali pa je del stavka if, else, while, do while, for, switch.

Primer1:

Pretvarjanje med tipi (type casting)

Pretvorba tipa (angl. Type casting) je postopek, pri katerem vrednost enega primitivnega podatkovnega tipa dodeliš drugemu tipu.

Kaj?

Primer:

int x1 = 9; //

byte y1 = x1; // dela? (DA/NE) ZAKAJ?

x1 -> y1 TA – x1 je večja »vedro«, y1 pa je manjše »vedro«, lahko prek teče? DA

Y1 -> x1

byte x2 = 9;

int y2 = x2 // dela? ZAKAJ? X2 (manjša) -> y2 (večja) - OK

Širjenje - Widening Casting

Widening Casting (automatically) - converting a smaller type to a larger type size (pretvarjanje manjšega tipa v večjega
byte -> short -> char -> int -> long -> float -> double

Ožanje - Narrowing Casting (manually) - converting a larger type to a smaller size type (pretvajanje večjega v manjšega)
double -> float -> long -> int -> char -> short -> byte

Naloga: Kaj vse lahko napišemo na mesto vprašaja?

Odprta naloga – rešitev preveri sam ali z učiteljem.
double x = 9.1;
int y = ( ? )x; // lossy conversion
