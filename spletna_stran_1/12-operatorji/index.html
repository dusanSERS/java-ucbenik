Prirejanje

Operatorji prirejanje v javi so (=; +=, -=, /=, *=, %= - »hitri« operatorji prirejanja)

Navadno prirejanje (assignment) =.

Kako deluje? Izraz na desni strani operatorja se izračuna (ovrednoti; izvede). Dobljena vrednost se shrani v spremenljivko na levi strani operatorja.

Primer 1:

x = 1;

Postopek:

Celo število 1 se shrani v spremenljivko x.

Primer 2:

x = 4 + y*(3 + z);

Postopek:

  1. Izračuna se 4 + y*(3 + z);

  2. rezultat se shrani v spremenljivko x

Primer 3:

x = scn.nextInt();

Postopek:

  1. Program se ustavi (ukaz scn.nextInt()). Uporabnik preko tipkovnice vpiše poljubno vrednost in pritisne enter.

  2. Če je vpisana vrednost celo število, se to število shrani v spremenljivko x.

  3. Če vpisana vrednost ni celo število, program javi napako in se zaustavi.

Več o ostalih operatorjih prirejanja kasneje.

Aritmetični

Aritmetični operatorji v Javi so:

+ - * / % ++ --

Njihova uporaba je odvisna od podatkovnega tipa, nad katerim jih izvajamo.

1) Celoštevilski tipi

byte, short, int, long

Kako delujejo?

  • Vse operacije se izvedejo kot celoštevilske.

  • Pri deljenju / rezultat nikoli ni decimalen, ampak se decimalni del odreže (truncation).

  • Presežki (overflow) se ne javijo kot napaka, ampak se vrednost “prelije”.

Primeri

int a = 7 / 2; // 3
int b = 10 % 3; // 1
int c = 2147483647;

System.out.println(b); // 2147483647

b++;
System.out.println(b); // -2147483648

2) Decimalni tipi

float, double

Kako delujejo?

  • Operacije se izvedejo kot realna (floating-point) aritmetika.

  • / vrne decimalno vrednost.

  • % je dovoljen in vrne preostanek pri deljenju z decimalkami.

  • Zaradi IEEE 754 standarda lahko pride do majhnih zaokrožitvenih napak.

Primeri

double x = 7.0 / 2; // 3.5
float y = 5.5f % 2; // 1.5

3) Znakovni tip

char

Kako delujejo?

  • char se pri aritmetiki pretvori v svoj Unicode številčni zapis.

  • Operacije vrnejo int, razen če rezultat pretvorimo nazaj.

Primeri

char a = 'A'; // 65 v Unicode
char b = 'C'; // 67
int razlika = b - a; // 2
char naslednji = (char) ('A' + 1); // 'B'

// (char) - eksplicitna pretvorba – kasneje bolj natančno

4) Logični tip

boolean

Aritmetični operatorji se NE smejo uporabljati nad boolean!

+ - * / % ++ -- → niso dovoljeni, povzročijo napako pri prevajanju.

Nizi znakov

String

Posebnost

  • Operator + deluje kot združevanje (konkatenacija).

  • Pri operaciji String + karkoli se drugi operand pretvori v niz.

Primeri

String ime = "Ana" + " " + "Novak"; // "Ana Novak"
String x = "Rezultat: " + 5; // "Rezultat: 5"

Ostali aritmetični operatorji (-, *, /, %) z String niso dovoljeni.

Naloga: Kaj izpiše sledeči program? Zapiši pravilo!

Odprta naloga – rešitev preveri sam ali z učiteljem.
System.out.println("1" + "2");
System.out.println("1" + 2);
System.out.println(1 + "2");
System.out.println(1 + 2);
System.out.println(1 + 2 + "3");
System.out.println(1 + 2 + 3);
System.out.println(1 + 2 + "3" + 4 + 5);
System.out.println(1 + 2 + "3" + (4 + 5));

primera:

x += y ~ x = x + y

Operator inkrement in dekrement (++,--)

Namenjena krajšemu zapisu. Poveča vrednost spremenljivke za 1.

++x (poveča x za 1) – prefixni – najprej poveča x in nato izvede stavek (npr. izpiše)

x++ (poveča x za 1) – postfixni – najprej izvede stavek (npr. izpiše) in nato poveča

Primer:

int x = 1; //
System.out.print(x+1); // izpiše 2, spr. x se ne spremeni
System.out.print(x); // izpiše 1

x++; // x se poveča za 1 -> v x je shr. 2

x=x+1; // x se poveča za 1 -> v x je shr. 3

System.out.print(x++); // izpiše 3, nato se x poveča za 1, x je 4
System.out.print(++x); // x se poveča za 1, x je 5, izpiše se 5
System.out.print(x); // izpiše se 5

Opozorilo:

Podobno kot x = x + 1, vendar pri nekaterih tipih ni treba uporabiti širjenja (ožanja) – casting. Več o tem kasneje.

Primerjalni

(==, !=, <, <=, >, >=)

  • V programiranju se primerjalni operatorji uporabljajo za primerjavo dveh vrednosti ali dveh spremenljivk.

  • Rezultat primerjalne operacije je vedno logična vrednost (true ali false).

  • Uporablja se v krmiljenju programov (pogojni stavki, zanke).

  • »Obnašanje« teh operatorjev se lahko razlikuje glede na podatkovne tipe, ki jih primerjamo.

Tukaj je podrobna razlaga za različne podatkovne tipe:

Realna števila

Primerjava med realnimi števili (float in double) lahko povzroči nepričakovane rezultate zaradi »težav« z natančnostjo (npr. 0.1 + 0.2 == 0.3 => false).

System.out.println(0.1 + 0.2); // 0.30000000000000004
System.out.println(0.3); // 0.3
System.out.println(0.1 + 0.2 == 0.3); // false

Primerjavo zato raje opravimo tako (ena izmed možnosti):

double a = 0.1 + 0.2;
double b = 0.3;
double epsilon = 1e-9; // Definiramo toleracno
(1*10-9)
if (Math.abs(a - b) < epsilon) {
System.out.println("a in b (skoraj) enaka");
}

else {

System.out.println("a in b nista enaka");
}

Razlaga:

  • Math.abs(a - b): Izračuna absolutno vrednost razlike med a in b.

  • epsilon: Prag tolerance. Izberite ga glede na zahtevano natančnost (npr. 1e-9 za zelo majhne razlike).

0.1 + 0.2 = 0.30000000000000004
0. 30000000000000004 – 0. 30000000000000000 = 0. 00000000000000004
0.00000000000000004 < 0.0000000001 -> true

Izbira primernega epsilona:

  • splošno primerna natančnost: 1e-9 ali 1e-10

  • nizka natančnost: 1e-6 ali 1e-7

  • visoka natančnost: 1e-12 = 1 * 10-12

Logični operatorji

(&&, ||, !)

  • Uporablja se za združevanje dveh ali več logičnih izrazov ali vrednosti.

  • Vrnejo logično vrednosti (true ali false).

  • Večinoma se uporabljajo v pogojnih stavkih in zankah.

Primer:

Če je vpisana ocena večja ali enaka 1 in manjša ali enaka 5, vpiši v redovalnico.

if( ocena >= 1 && ocena <= 5)

vpisiVRedovalnico(ocena)

Logični AND (&&) se uporablja, kadar morajo biti vsi pogoji izpolnjeni.

  • Opis: Vrednost je true samo, če sta oba operanda true.

  • Uporaba: Pogosto uporabljen, kadar morajo biti izpolnjeni vsi pogoji.

  • Primer: Geslo mora imeti vsaj 5 znakov in vsaj dve črki in vsaj eno ne črko in eno številko

Operand 1 Operand 2 Rezultat (op1&& op2)
true true true
true false false
false true false
false false false 
public class LogicalAndExample {
public static void main(String[] args) {
int a = 5;
int b = 10;
if (a > 0 && b > 0) {
System.out.println("Obe števili sta pozitivni.");
}
}
}

// Izhod: Obe števili sta pozitivni.

Logični OR (||)

  • Opis: Vrednost je true, če je vsaj en operand true.

  • Uporaba: Pogosto uporabljen, kadar je dovolj, da je izpolnjen le en pogoj.

op1 op2 Rezultat (op1|| op2)
true true true
true false true
false true true
false false false 
public class LogicalOrExample {
public static void main(String[] args) {
int a = -5;
int b = 10;
if (a > 0 || b > 0) {
System.out.println("Vsaj eno število je pozitivno.");
}
}
}

// Izhod: Vsaj eno število je pozitivno.

Logični NOT (!)

  • Opis: Negira logično vrednost. Če je vrednost true, vrne false in obratno.

  • Uporaba: Pogosto uporabljen za obrat pogojev.

Operand Rezultat (!operand)
true false
false true 
public class LogicalNotExample {
public static void main(String[] args) {
boolean isActive = false;
if (!isActive) {
System.out.println("Sistem ni aktiven.");
}
}
}

// Izhod: Sistem ni aktiven.

Kratko stikanje (Short-Circuiting)

Logična operatorja && in || v Javi sta kratkostična operatorja, kar pomeni:

  • Za &&: Če je prvi pogoj false, se drugi pogoj ne preverja, ker rezultat ne more biti true.

  • Za ||: Če je prvi pogoj true, se drugi pogoj ne preverja, ker rezultat ne more biti false.

public class ShortCircuitingExample {
public static void main(String[] args) {
int x = 5;
if (x > 0 || ++x > 5) { // Drugi pogoj se ne preverja
System.out.println("Prišlo je do kratkega stikanja.");
}
System.out.println(x); // Izhod: 5 (x se ne poveča)
}
}

De Morganova zakona

De Morganov zakon v pogojnih stavkih se uporablja za preoblikovanje logičnih izrazov. V bistvu gre za pravilo, ki olajša delo z negacijami kompleksnih logičnih izrazov. Ta zakon pravi, da lahko negacijo kombinacije izrazov preoblikujemo z uporabo nasprotnih operatorjev in negacije posameznih izrazov.

De Morganova zakona

Negacija logičnega AND (&&):

  • Negacija kombinacije z AND je enaka logični OR negacij posameznih pogojev.

  • Pravilo: !(A && B) je logično enak zapis kot (!A) || (!B)

Primer v Javi:

if (!(x > 0 && y > 0)) ...

// Enako kot:

if (!(x > 0) || !(y > 0)) ...

// Enako kot

if ( x <= 0 || y <= 0 ) ...

Negacija logičnega OR (||):

  • Negacija kombinacije z OR (!(A || B)) je enaka logičnemu AND negacij posameznih pogojev.

  • Pravilo: !(A || B) ) je logično enak zapis kot (!A) && (!B)

if (!(x > 0 || y > 0)) ...

// Enako kot:

if (!(x > 0) && !(y > 0 ) ...

// Enako kot:

if (x <= 0 && y <= 0) ...

Pomen De Morganovih zakonov

  • Poenostavljanje pogojev: Z uporabo De Morganovih zakonov lahko kompleksne pogoje preoblikujemo v lažje razumljive izraze.

  • Izogibanje napakam: V kombinaciji z logičnimi negacijami so preoblikovani pogoji pogosto jasnejši in manj nagnjeni k napakam.

  • Izboljšana berljivost kode: Čeprav sta oba izraza funkcionalno enaka, je pogosto eden lažje razumljiv kot drugi.

Primer praktične uporabe

Pred preoblikovanjem:

if (!(age > 18 || hasLicense)) {
System.out.println("Ne sme voziti.");
}

Po preoblikovanju z De Morganovim zakonom:

if (age <= 18 && !hasLicense) {
System.out.println("Ne sme voziti.");
}

Prioriteta operatorjev (prednost operatorjev v Javi )

V programskem jeziku Java imajo operatorji različno prednost izvajanja. To pomeni, da se nekateri deli izraza izvedejo prej kot drugi.

Operatorji, ki imajo višjo prednost, se izvedejo najprej. Operatorji, ki so v tabeli (spodaj) zapisani višje, imajo večjo prednost kot tisti spodaj. Če sta operatorja v isti vrstici, imata enako prednost.

Kadar ima več operatorjev enako prednost, velja pravilo:

  • večina operatorjev se izvaja z leve proti desni,

  • operatorji prirejanja (npr. =) pa se izvajajo z desne proti levi.

Zato je pomembno, da pri zapletenih izrazih:

  • poznamo prednost operatorjev,

  • po potrebi uporabimo oklepaje, da jasno določimo vrstni red izvajanja.
