Sintaksa (syntax)

Sintaksa pomeni pravila, po katerih mora biti koda pravilno zapisana, da jo Java lahko prevede.

Primeri pravil sintakse:

  • stavek mora imeti podpičje:

int x = 5;

  • oklepaji morajo biti pravilno zaprti:

if (x > 0) { ... }

  • spremenljivke se morajo deklarirati pred uporabo:

int starost;

  • ime razreda mora ustrezati imenu datoteke, če je razred public.

Kaj se zgodi, če sintaksa NI pravilna?

Java izpiše napako pri prevajanju (compile-time error), npr.:

';' expected

Sintaktične napake preprečijo, da bi izdelali vmesno kodo in da bi program lahko zagnali.

Semantika

Semantika pomeni pomen kode – kaj program dejansko naredi, ko se izvaja.

Gre za logiko in smisel, podobno kot pomen stavkov v naravnem jeziku.

Primer: sintaktično pravilno, semantično napačno

int x = 10 / 0;

  • Sintaksa je OK (vse je pravilno zapisano).

  • Semantika je napačna, ker deljenje z 0 nima smisla → med izvajanjem dobimo napako:

ArithmeticException: / by zero

Drug primer:

int starost = -5;

  • Sintaksa OK.

  • Semantično pa starost −5 nima smisla → logična napaka, program sicer teče, a napačno.

Pri semantičnih napakah torej pride do dveh možnosti:

  • Program se prevede vendar ne deluje pravilno. Če nismo pazljivi, tega sploh ne opazimo.

  • Program se prevede. Med izvajanjem se zaustavi in javi napako vrste RunTimeError.

Povzetek - najkrajša razlaga

  • Sintaksa = “Ali je pravilno zapisano?”

  • Semantika = “Ali dela to, kar mora?”

Zgradba programa

  • Vsaka koda v Javi je zapisana znotraj razreda (ang. class).

  • Če je razred public, mora imeti datoteka enako ime kot ta razred. (Dokler ne spoznamo podrobnosti določila puiblic, bodo vsi razredi public)

  • Datoteke s kodo v Javi imajo končnico .java.

  • Datoteka lahko vsebuje več razredov, vendar je lahko največ en označen kot public.
    Tisti public razred določa ime datoteke.

  • Imena razredov pišemo z veliko začetnico. ostala pravila so enaka kot za imena spremenljivk.

public class Main {
public static void main(String[] args) {

// začetek izvajanje izvajanja programa – začetek metode main

System.out.println("Hello World");

// konec izvajanja programa – konec metode main

}
}
ime datoteke: Main.java

Osnovna pravila izvajanja programa v javi

  1. Program se začne izvajati v metodi main

Odprta naloga – rešitev preveri sam ali z učiteljem.

  • Java program se vedno začne izvajati pri tej metodi:

    • public static void main(String[] args)

  • Brez te metode se program ne zažene (razen pri posebnih primerih, npr. JavaFX).

  1. Izvajanje poteka od zgoraj navzdol

Odprta naloga – rešitev preveri sam ali z učiteljem.

  • Java izvršuje vrstice po vrsti, tako kot so zapisane v metodi main.

  • Obstajajo izjeme:

    • pogojni stavki (if, else) lahko kakšno kodo preskočijo,

    • zanke (for, while, do-while) lahko del kode ponavljajo večkrat,

    • return lahko predčasno zaključi metodo.

    • break (prekine zanko, prekine stavek switch)

  1. Stavek se zaključi s podpičjem ;

Odprta naloga – rešitev preveri sam ali z učiteljem.

  • V Javi večina izjav (statements) konča vrstico z ;

int x = 5;
System.out.println(x);

  • Izjema so kontrolne strukture in bloki, ki nimajo podpičja:

    • if (...) { ... }
    • for (...) { ... }
    • while (...) { ... }

    • definicija metode

    • definicija razreda

Osnovna pravila oblikovanja kode (indentacija)

  1. Po vsakem odpiralnem zavitem oklepaju { naredimo zamikanje v desno

Odprta naloga – rešitev preveri sam ali z učiteljem.

Primer:

if (x > 0) {
System.out.println("Pozitivno");
}

  1. Vse vrstice znotraj bloka so zamaknjene

  • obvezno zamaknemo s tipko TAB (ki vstavi nevidni znak TAB ali včasih štiri (lahko tudi dva) presledka

  • to izboljša berljivost in razumevanje kode

  1. Ko uporabimo zaključni oklepaj }, gremo z zamikom eno stopnjo nazaj

Primer:

for (int i = 0; i < 5; i++) {
System.out.println(i);
}
System.out.println();// ← tukaj ni več zamika
