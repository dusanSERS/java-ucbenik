JVM (virtualni stroj java, ang.: java virtual machine, sklad (ang.: Stack) in kopica (ang.: Heap)

Ko zaženemo Java program, ga izvaja JVM (Java Virtual Machine).
JVM upravlja pomnilnik in skrbi, kje se shranjujejo podatki programa.

JVM

JVM je program, ki poganja Java programe.

Njene naloge so:

  • izvajanje Java kode

  • upravljanje pomnilnika

  • nalaganje razredov

  • samodejno brisanje neuporabljenih objektov (garbage collector)

Stack (sklad)

Stack je del pomnilnika, kjer se shranjujejo:

  • lokalne spremenljivke

  • parametri metod

  • klici metod

Vsakič ko pokličemo metodo, se na stack doda nov okvir metode (stack frame).

Primer:

void metoda(int x)

Parameter x se shrani na stack.

Ko metoda konča izvajanje, se njen okvir odstrani.

Heap (kopica)

Heap je del pomnilnika, kjer se shranjujejo:

  • objekti

  • polja

  • večje strukture podatkov

Primer:

Oseba o = new Oseba();

Objekt Oseba se ustvari na heapu.

Spremenljivka o pa vsebuje referenco (naslov) do tega objekta.

Povezava s prenosom parametrov

Prenos vrednosti (primitive)

void spremeni(int x)

  • x je kopija vrednosti

  • sprememba v metodi ne vpliva na originalno spremenljivko

Ker se vrednost kopira na stack.

Prenos reference (objekti)

void spremeni(Oseba o)

  • kopira se referenca do objekta

  • metoda lahko spremeni objekt na heapu

Zato spremembe vidimo tudi izven metode.

Preprost povzetek

Del pomnilnika Kaj vsebuje
JVM poganja Java program
Stack parametri metod in lokalne spremenljivke
Heap objekti in polja
