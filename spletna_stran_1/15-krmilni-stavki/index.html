Krmilni stavki

Pogojni stavkiStavek ifStavek if-elseStavek switchTako deluje:Komentarji:Dodatno interaktivno preverjanje

Krmilni stavki (ang. control statements) so stavki v programskem jeziku java, s katerimi nadzorujemo potek izvajanja programa. Omogočajo nam, da program ne teče samo od zgoraj navzdol, temveč lahko določene stavke:

  • ponavljamo ali

  • preskočimo.

Ponavljanje in/ali preskakovanje je odvisno od pogojev, ki so del krmilnih stavkov in jih programer zapiše v programsko kodo v za to predviden prostor.

Stavkom, ki izvedejo samo določen del kode, pravimo pogojni stavki.

Stavkom, ki ponavljajo določen del kode pravimo zanke.

  • If

  • If – else

  • switch case

Stavek switch

Namesto pisanja številnih stavkov if..else lahko v nekaterih primerih uporabimo stavek switch.

Predstavljamo si ga lahko kot naročanje hrane v restavraciji:

  • Če izbereš številko 1, dobiš pico.

  • Če izbereš 2, dobiš burger.

  • Če izbereš 3, dobiš testenine.

  • V nasprotnem primeru ne dobiš ničesar.

Stavek switch lahko nadomesti if-else takrat, ko v pogojnem stavku uporabljamo operator je enako (==). Ne moremo pa gu uporabiti v primerih, ko bi želeli nadomestiti ostale primerjalne ali logične operatorje (<, >, ||, ...).

Stavek switch izbere enega izmed več blokov kode, ki se nato izvede.

Sintaksa stavka switch:

switch(izraz)

{

case x:

// stavki 1 (blok kode)

break;

case y:

// stavki 2 (blok kode)

break;

...

default:

// stavki 3

break;

}

Tako deluje:

  • Izraz v switch se ovrednoti samo enkrat. (izraz je lahko računska

  • Rezultat se primerja z vsako vrednostjo case. (primerjava je lahko samo ==, ne pa tudi <, >, <=, >=, !=)

  • Če se katera ujema, se izvede ustrezni blok kode.

  • break zaustavi izvajanje switch po izvedenem ujemajočem se primeru.

  • če stavkom ne sledi break, se izvede naslednji primer (case), brez primerjave

  • default se izvede, če ni nobenega ujemanja

primer switch:

import java.util.Scanner;

public class Restavracija

{

public static void main(String[] args)

{

Scanner sc = new Scanner(System.in);

System.out.print("Izberi številko (1–3): ");
int izbira = sc.nextInt();

switch (izbira)

{

case 1:

System.out.println("Dobiš pico.");

break;

case 2:

System.out.println("Dobiš burger.");

break;

case 3:

System.out.println("Dobiš testenine.");

break;

default:

System.out.println("Ne dobiš ničesar.");

break;

}

sc.close();

}
}

Komentar:

Spremenljivka izbira se primerja z vrednostmi m ali ž. Težava nastopi, če uporabnik vpiše veliko črko M. TO lahko rešimo na različne načine. Lahko bi vpisano črko pretvorili v malo črko, mi pa bomo v naslednjem primeru naredili primerjavo z malo in veliko črko.

  • Programski stavki se izvajajo en za drugim (navzdol)
