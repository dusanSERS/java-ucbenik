String Length

A String in Java is actually an object, which contain methods that can perform certain operations on strings.

For example, the length of a string can be found with the length() method:

String txt = "ABCDEFGHIJKLMNOPQRSTUVWXYZ";
System.out.println("The length of the txt string is: " +
txt.length());

Ker je String razred (podobno kot Random, Scanner, Math, ..) iz njega naredimo objekt in ne spremenljivke. Uporabimo ključno besedo new. Primer:

String txt = new
String("ABCDEFGHIJKLMNOPQRSTUVWXYZ");
System.out.println("The length of the txt string is: " +
txt.length());

Ključna razlika med spremenljivko in objektom je v tem, da je objekt instanca razreda, ki živi (Se shrani) na kopici, spremenljivka pa je ime, prostor na skladu, ki ima svoje ime in v katerega lahko shranimo vrednost ali referenco (naslov).

Primeri spremenljivke:

int x;
boolean y;
String name;

Primeri objektov:

new Random()

new String()

new Scanner(System.in)

Stringi v Javi so nespremenljivi. Do posameznih elementov lahko dostopamo z metodo charAt(1), podobno kot v poljih (array) polje[1], ne moremo pa jih spreminjati, kar pa za polja ne velja.

int [] polje = {1,2,3};

String stavek = "Danes je lep dan!";
System.out.print(polje[0]);
System.out.print(stavek.charAt(0));
System.out.print(stavek[0]);

polje[0] = 5; // elemente v polju lahko spreminjamo

stavek.charAt(0) = "S"; // znakov v Stringu ne moremo spreminjati

Method Description Example
length() Returns number of characters name.length() → 3
charAt(int) Gets character at position name.charAt(0) → 'A'
toUpperCase() All characters to uppercase name.toUpperCase() → "ANA"
contains(String) Checks if it contains part name.contains("n") → true
equals(String) Compares two Strings "Ana".equals("ana") → false
substring(int, int) Gets part of the String "Hello".substring(0, 2) → "He" 
public class StringExample {
public static void main(String[] args) {
String name = "Julija";
System.out.println("Name: " + name);
System.out.println("Length: " + name.length());
System.out.println("First letter: " + name.charAt(0));
System.out.println("Uppercase: " + name.toUpperCase());
System.out.println("Contains 'li': " + name.contains("li"));
}
}

+

Združevanje nizov.

Če imamo dva (ali več) stringa ju z operatorjem + združimo v enega.

Če je na eni strani opertorja + string, se drugi operand avtomatično pretvori v string.

 
String firstName = "Ana";
String lastName = "Novak";
String fullName = firstName + " " + lastName;
System.out.println(fullName); // Ana Novak
String result = "Age: " + 30; // "Age: 30"
String a = "a" + 1.5f;

a = "a" + "a";

a = "a" + 1.5f;

a = "a" + 1;

a = "a" + '1';

a = "a" + true;
