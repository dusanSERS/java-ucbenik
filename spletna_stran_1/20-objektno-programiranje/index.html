Uvod

Pri proceduralnem programiranju je program sestavljen iz funkcij in podatkov, ki so pogosto ločeni. Tak pristop je primeren za manjše programe, vendar pri večjih sistemih hitro postane nepregleden. Podatki se prenašajo med funkcijami, kar povečuje možnost napak.

Z razvojem večjih informacijskih sistemov (programov) se je pojavila potreba po bolj strukturiranem pristopu. Objektno programiranje (OOP – object oriented programming) rešuje ta problem tako, da združi podatke in funkcije v eno celoto – objekt.

Zgodovinsko gledano se je OOP začel razvijati v 80. letih z jeziki kot so Smalltalk, kasneje C++ in Java. (Programski jezik C na primer ni OO-PJ)

Osnovni pojmi objektnega programiranja

Razred (class) je načrt (ang. template ali blueprint) za ustvarjanje objektov. Objekt (object) je konkretna instanca (primerek) razreda. Atributi so lastnosti objekta, metode pa funkcije, ki delujejo nad podatki objekta.

Primer: preriši iz table.

razred: Dijak - vsak dijak ima lastnosti: ime, priimek, starost.

objekti: Tjaš, Alen, Hana, Daniela, … Vsi objekti imajo iste lastnosti, vendar druge vrednosti. Tjaš (ime: Tjaš, priimek: Neuvirt, starost:18). Alen (ime: Alen, priimek: Sužnik, starost: 18)...

Dijak d1 = new Dijak();

class Dijak {

String ime;
int starost;

void izpis() {

System.out.println(ime + " je star " + starost);
}
}
V tem primeru podatki niso povezani v celoto. Vsakič jih moramo prenašati kot parametre. V tem primeru so podatki in funkcije združeni v objektu. Program je bolj pregleden in lažje razširljiv.

Ključna ideja objektnega programiranja

Objektno programiranje združuje podatke in funkcionalnost v eno enoto. Tako dobimo bolj modularen, razumljiv in razširljiv program.

Rešujemo torej enake probleme vendar na drug način.
