Branje vrednosti iz tipkovnice (user input)

Za radovedne

Razred Scanner je namenjen branju uporabniškega vnosa. Nahaja se v paketu z imenom java.util. Ta paket moramo vključiti na začetku programa. Še pred definicijo razreda. Za vključevanje uporabimo ključno besedo import.

Če želimo uporabiti razred Scanner, moramo najprej ustvariti objekt in nato uporabimo primerno metodo odvisno, ali bomo brali cela števila, realna števila, niz, ... Če bomo brali cela števila, bomo uporabili metodo nextInt, če realna števila nextFloat, če besedilo nextLine …

Metode, ki jih lahko uporabimo:

Ime metode Opis
nextBoolean() Prebere vrednost boolean
nextByte() Prebere vrednost byte
nextDouble() Prebere vrednost double
nextFloat() Prebere vrednost float
nextInt() Prebere vrednost int
nextLine() Prebere vrednost String
nextLong() Prebere vrednost a long
nextShort() Prebere vrednost a short

Naloga:

Napiši program, kjer uporabnik vnese svoje podatke )ime, starost, teža, spol. Nato sledi izpis glede na spol.

Odprta naloga – rešitev preveri sam ali z učiteljem.
import java.util.Scanner; // vključevanje razreda

class Main {

public static void main(String[] args) {

Scanner myObj = new Scanner(System.in); // izdelava objekta z imenom myObj

System.out.print("Vpiši svoje ime:");
String ime = myObj.nextLine(); // uporaba metode
System.out.print("Vpiši svojo starost:");

byte starost = myObj.nextByte(); // uporaba metode

System.out.print("Vpiši svojo težo na eno decimalko:");
float teza = myObj.nextFloat(); // uporaba metode

myObj.nextLine(); // počisti ENTER (\n) iz bufferja

System.out.print("Vpiši svoj spol (m/z):");
char spol = myObj.nextLine().charAt(0); // char nima svoje metode -
moramo pretvoriti String v char - 0 prvi znak v nizu
System.out.println("Ime ti je: " + ime);

if( spol == 'm')

{
System.out.println("Star si: " + starost);
System.out.println("Težek si: " + teza);
}

else

{
System.out.println("Stara si: " + starost);
System.out.println("Težka si: " + teza + "kg");
}
System.out.print("KONEC PROGRAMA!");
}
}

D.N.: Doma dokončaj in preizkusi!

POZOR:

Če stavkom next() ali nextNEKAJ() sledi stavek nextLine(), moramo pred nextLine dodati še (prazen) stavek nextLine(). (glej primer zgoraj)

Za radovedne

Ko uporabiš nextByte() ali nextFloat(), v bufferju ostane znak za ENTER (\n).
Ko nato pokličeš nextLine(), ta takoj prebere ta preostanek, zato preskoči vnos spola in prikaže napako.
