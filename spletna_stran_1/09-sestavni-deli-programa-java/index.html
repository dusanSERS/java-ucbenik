Sestavni deli programa java

Program v javi je sestavljen iz sledečih elementov:

  • ključne besede,

  • identifikatorji,

  • literali,

  • operatorji,

  • ločila,

  • komentarji,

  • izjave,

  • bloki kode,

  • razredi, metode, bloki.

1) Ključne besede (keywords)

To so rezervirane besede, ki imajo v javi poseben pomen. Ne smeš jih uporabiti kot ime spremenljivke ali metode.

Primeri:
class, public, static, void, int, double, if, else, while, for, return, new, boolean, try, catch …

2) Identifikatorji (identifiers)

Imena, ki jih programer izbere sam:

  • imena spremenljivk (x, starost, temperatura)

  • imena metod (izracunajBMI())

  • imena razredov (Student)

  • imena paketov

3) Literali (literals)

To so konstantne vrednosti, zapisane neposredno v kodi:

  • številski: 10, 3.14, -5

  • znakovni: 'a', '\n'

  • nizovni: "Dober dan"

  • logični: true, false

  • null literal: null

4) Operatorji

Simboli, ki izvajajo operacije nad vrednostmi.

Matematični:

+ - * / %

Prireditveni:

=, +=, -=, *=, /=, %=

Primerjalni:

==, !=, <, >, <=, >=

Logični:

&&, ||, !

Povezovanje nizov:

+

5) Ločila (punctuation / separators)

Simboli, ki ločujejo dele kode.

Najpogostejša:

  • podpičje ; – konča stavek

  • vejice , – ločuje elemente

  • pika . – dostop do članov (objekt.metoda)

  • oklepaji:

    • () za metode, pogoje

    • {} za bloke kode (razredi, metode, if, while)

    • [] za tabele

  • dvojni dvopičji :: – reference na metode

  • dve poševnici // – komentar

6) Komentarji

Del kode, ki se ne izvede. Za razlago.

  • Enovrstični:

// to je komentar

  • Večvrstični:
    /* komentar ... */

  • Dokumentacijski (Javadoc):
    /** razlaga razreda ali metode */

7) Izjave (statements) – tudi stavki

Posamezni ukazi, ki jih Java izvede.

Primeri:

  • prireditev: x = 5;

  • pogoj: if (x > 10) {...}

  • zanka: for (int i=0; i<10; i++) {...}

  • return: return x;

8) Bloki kode

Koda v { }.

Primer:

if (a > b) {
System.out.println("A je večji");
}

9) Razredi, metode in paketi

Temeljne strukture:

  • paketi organizirajo datoteke (npr. package moj.program;)

  • razredi so osnovni gradniki Jave

  • metode izvajajo funkcionalnost

Naloga: Za spodnji program zapiši osnovne elemente programa java.

Odprta naloga – rešitev preveri sam ali z učiteljem.
import java.util.Scanner; // vključevanje razreda

class Main {

public static void main(String[] args) {

Scanner myObj = new Scanner(System.in); // izdelava objekta z imenom myObj

System.out.print("Vpiši svoje ime:");
String ime = myObj.nextLine(); // uporaba metode
System.out.print("Vpiši svojo starost:");

byte starost = myObj.nextByte(); // uporaba metode

System.out.print("Vpiši svojo težo na eno decimalko:");
float teza = myObj.nextFloat(); // uporaba metode

myObj.nextLine();

System.out.print("Vpiši svoj spol (m/z):");
char spol = myObj.nextLine().charAt(0); // char nima svoje metode -
moramo pretvoriti String v char - 0 prvi znak v nizu
System.out.println("Ime ti je: " + ime);

if( spol == 'm')

{
System.out.println("Star si: " + starost);
System.out.println("Težek si: " + teza);
}

else

{
System.out.println("Stara si: " + starost);
System.out.println("Težka si: " + teza + "kg");
}
System.out.print("KONEC PROGRAMA!");
}
}

Rešitev:

1) Ključne besede (keywords)

Ključne besede v tem programu:

  • import

  • class

  • public

  • static

  • void

  • new

  • tipi: byte, float, char, String (tip je poseben primer – String je razred, ne keyword, ampak za dijake ga navadno obravnavamo skupaj z ostalimi tipi)

  • if, else

2) Identifikatorji (imena)

To so imena, ki si jih izberemo sami (ali jih je izbral nekdo v knjižnici):

  • Imena razredov:

    • Main (tvoj razred)

    • Scanner (razred iz knjižnice)

  • Imena spremenljivk:

    • myObj

    • ime

    • starost

    • teza

    • spol

    • args (parameter metode main)

  • Imena metod:

    • main

    • println

    • print

    • nextLine

    • nextByte

    • nextFloat

    • charAt

  • Imena paketov (v importu):

    • java

    • util

    • Scanner (zadnji del importa je razred v paketu)

3) Literali

To so vrednosti, zapisane “na trdo” v kodi:

  • Nizovni literali (String):

    • "Vpiši svoje ime:"

    • "Vpiši svojo starost:"

    • "Vpiši svojo težo na eno decimalko:"

    • "Vpiši svoj spol (m/z):"

    • "Ime ti je: "

    • "Star si: "

    • "Težek si: "

    • "Stara si: "

    • "Težka si: "

    • "kg"

    • "KONEC PROGRAMA!"

  • Znakovni literali (char):

    • 'm'

    • 0 v charAt(0) je dejansko številski literal tipa int, uporablja se kot indeks.

  • V tem programu ni logičnih literalov (true, false) in ni null.

4) Operatorji

V tvojem programu nastopajo:

  • Prireditveni:

    • =

    • Scanner myObj = new Scanner(System.in);

    • String ime = myObj.nextLine();

    • byte starost = myObj.nextByte();

    • float teza = myObj.nextFloat();
    • char spol = myObj.nextLine().charAt(0);

  • Primerjalni:

    • ==

    • if (spol == 'm')

  • Povezovanje nizov:

    • +

    • System.out.println("Ime ti je: " + ime);
    • System.out.println("Star si: " + starost);
    • System.out.println("Težka si: " + teza + "kg");

Aritmetičnih (+ - * / %) tukaj ne uporabljamo za računanje, samo za lepljenje nizov.

5) Ločila (separators / punctuation)

Nekaj primerov iz programa:

  • Podpičje ; – konča izjavo:

    • import java.util.Scanner;

    • Scanner myObj = new Scanner(System.in);

  • Vejice , – ločujejo elemente v seznamu parametrov:

    • v tem programu je nimaš, a bi jo recimo imel v metodi z več parametri.

  • Pika . – dostop do članov:

    • System.out.println(...)

    • myObj.nextLine()

    • System.in

  • Oklepaji ():

    • pri klicu metod: main(String[] args), nextLine(), nextByte(), charAt(0), println("...")

    • pri pogoju: if (spol == 'm')

  • Zaviti oklepaji { } – bloki:

    • telo razreda Main { ... }

    • telo metode main { ... }

    • telesi if { ... } in else { ... }

  • Oglati oklepaji []:

    • pri parametru String[] args – polje nizov.

  • Dvojni dvopičji :: in // v tem programu ne nastopata.

6) Komentarji

V tem konkretnem programu nimaš komentarjev, ampak bi jih lahko imel, npr.:

// Uvozimo razred Scanner

import java.util.Scanner;

ali

/* Večvrstični komentar

o delovanju programa */

7) Izjave (statements)

Vsak “ukaz”, ki se izvede:

  • Import (na vrhu datoteke):

    • import java.util.Scanner;

  • Ustvarjanje objekta:

    • Scanner myObj = new Scanner(System.in);

  • Izpis in branje:

    • System.out.print("Vpiši svoje ime:");
    • String ime = myObj.nextLine();
    • System.out.print("Vpiši svojo starost:");

    • byte starost = myObj.nextByte();

    • System.out.print("Vpiši svojo težo na eno decimalko:");
    • float teza = myObj.nextFloat();

    • myObj.nextLine();

    • System.out.print("Vpiši svoj spol (m/z):");
    • char spol = myObj.nextLine().charAt(0);

  • Izpis:

    • System.out.println("Ime ti je: " + ime);

  • Pogojna izjava if z else:

    • if (spol == 'm') {
    • System.out.println("Star si: " + starost);
    • System.out.println("Težek si: " + teza);

    • } else {

    • System.out.println("Stara si: " + starost);
    • System.out.println("Težka si: " + teza + "kg");

  • Zadnji izpis:

    • System.out.print("KONEC PROGRAMA!");

Vsaka vrstica, ki se konča s ;, je izjava. if (...) { ... } else { ... } je sestavljena izjava s pod-bloki.

8) Bloki kode

Blok = koda med { in }:

  • Blok razreda:

class Main {

// vse to je blok razreda Main

}

  • Blok metode main:

public static void main(String[] args) {

// celoten program tukaj

}

  • Blok if:

if (spol == 'm') {
System.out.println("Star si: " + starost);
System.out.println("Težek si: " + teza);
}

  • Blok else:

else

{
System.out.println("Stara si: " + starost);
System.out.println("Težka si: " + teza + "kg");
}

9) Razredi, metode, paketi

  • Paket / knjižnica:

import java.util.Scanner;

java.util je paket, kjer se nahaja razred Scanner.

  • Razred:

class Main {

...

}

To je tvoj glavni razred.

  • Metoda main:

public static void main(String[] args) {

...

}

Vhodna točka programa.

Ključne besede: public static void

Parametri: String[] args

  • Metode, ki jih uporabljaš:

new Scanner(System.in) – konstruktor razreda Scanner

myObj.nextLine(), myObj.nextByte(), myObj.nextFloat() – metode za branje

myObj.nextLine().charAt(0) – najprej metoda nextLine(), nato metoda charAt(0) na vrnjenem nizu

System.out.print(...), System.out.println(...) – metode za izpis na zaslon

Naloga: V programu označi sestavne dele programa in jih poimenuj.

Odprta naloga – rešitev preveri sam ali z učiteljem.
public class Main {
public static void main(String[] args) {
System.out.println("Pozdravljen!");
System.out.println("Dobrodošel v Javi.");
int a = 10;
int b = 5;
int vsota = a + b;
System.out.println("Vsota je: " + vsota);
System.out.println("Lep dan!");
}
}
